# 고정 윈도우

나의몰 한도: 1초에 2번. 한 버전 끝나면 `cp v1.ts v2.ts` 하고 다음 문제.

```sh
node fixed-window/v1.ts
```

## v1

`fixedWindow(nowMs) → true(통과) | false(거절)`

기대: `100 true · 200 true · 300 false · 1100 true · 1200 true · 1300 false`

## 다음 문제

- **v2** 거절할 때 `false` 대신 "몇 ms 뒤에 다시 오라"를 돌려줘라. 통과면 0.
- **v3** Redis 에 `KEYS *` 를 쳐 봐라. 창마다 키가 쌓인다. 안 쌓이게 해라.
- **v4** 화주가 여럿이다. 화주 A가 한도를 다 써도 화주 B는 통과해야 한다.
- **v5** 같은 순간 10개가 동시에 온다. 정확히 2개만 통과하나? INCR 대신 GET → 비교 → SET 으로 바꿔서 깨지는 걸 봐라.
- **v6** 한 번 부를 때 2칸을 쓰는 API 가 있다 (cost).
- **v7** 거절된 요청도 카운트가 올라가 있다. 문제인가? 고쳐야 하나?
- **v8** 0.9·0.95·1.05·1.1초에 4번 보내 봐라. "1초에 2번"이 지켜졌나? → 슬라이딩 윈도우로 넘어간다.
