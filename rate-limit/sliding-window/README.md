# 슬라이딩 윈도우

고정 윈도우 v8 을 보고 온다. 나의몰 한도: 아무 1초 구간을 잘라도 2번. 한 버전 끝나면 `cp v1.ts v2.ts` 하고 다음 문제.

```sh
node sliding-window/v1.ts
```

## v1 — 슬라이딩 로그 (ZSET)

`node sliding-window/v1.ts` 가 `통과` 를 찍으면 끝.
