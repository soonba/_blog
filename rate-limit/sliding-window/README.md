# 슬라이딩 윈도우

고정 윈도우 v8 을 보고 온다. 나의몰 한도: 1초에 2번.

```sh
node sliding-window/v1.ts
```

## v1 — 슬라이딩 로그 (ZSET)

`slidingLog(nowMs) → true | false` — "지금부터 거꾸로 1초" 안의 요청 수로 판정.

기대: `900 true · 950 true · 1050 false · 1100 false · 1950 true`
